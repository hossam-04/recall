# recall

A spaced-repetition system for interview prep, built end to end in TypeScript.

Cards can be written by hand, or generated by Claude from a subject or from
pasted source material. Generated cards land in a review queue — nothing enters
the bank without being approved first.

**Status: M3 done.** A React UI over an HTTP API with session auth and CSRF,
on Postgres with hand-written SQL. Reviews are keyboard-driven: space reveals,
1-4 grade. `npm run verify` runs four layers — typecheck, 81 unit and
integration tests, a curl smoke test against a real socket, and Playwright
against real Chromium.

```bash
npm run dev     # api on :3000, ui on :5173
```

The terminal review CLI from M1 has been retired — it kept its own JSON decks
and recorded no review events, so it and the app disagreed about both the data
and the design. The scheduler it was built to exercise
([`src/scheduler/sm2.ts`](src/scheduler/sm2.ts)) is unchanged and is what the
API grades with. See ADR-028.

## Why this exists

This is a learning project. The goal is not the product — it is the assembly:
HTTP boundaries, session auth, relational modelling, a browser UI, three layers
of tests, and an LLM integration with structured outputs, cost accounting, and
an eval suite. Design decisions are recorded in
[`claude/DECISIONS.md`](claude/DECISIONS.md); progress and open questions in
[`claude/PROGRESS.md`](claude/PROGRESS.md).

## Requirements

- Node >= 26
- PostgreSQL 18 (keg-only on Homebrew — `psql` needs
  `export PATH="/opt/homebrew/opt/postgresql@18/bin:$PATH"`)

## Setup

```bash
brew install node postgresql@18
brew services start postgresql@18
createdb recall
npm install
cp .env.example .env
```

## Commands

| Command | What it does |
|---|---|
| `npm run verify` | The done condition. All four layers. Exits 0 or it isn't done. |
| `npm run dev` | API on :3000, UI on :5173 |
| `npm test` | Unit and integration tests |
| `npm run e2e` | Playwright against real Chromium |
| `npm run smoke` | Drives a real server over a real socket with curl |
| `npm run migrate` | Apply pending migrations |
| `npm run typecheck` | `tsc --noEmit`, strict, both tsconfigs |

`npm run eval` arrives with M5.

> `npm run eval` will call the real Claude API and cost real money. It never runs
> in CI and never runs as part of `verify`.

**M4 and M5 are deferred for cost.** They need roughly $20–40 of Anthropic API
credits, which a Claude subscription does not provide — API usage is metered
separately. `claude/PROGRESS.md` lists what is being built in their place.

## What this does not do

No deployment, no deck sharing, no images or syntax highlighting on cards, no
file uploads, no mobile layout. See the scope cuts in `claude/PROGRESS.md`.
